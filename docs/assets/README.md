# README visual assets

These assets belong to the AccessLab GitHub README. Keep this folder at `docs/assets/` when uploading the project.

| File | Purpose |
| --- | --- |
| accesslab-banner.svg | Static vector project banner |
| stack-badges.svg | Local technology labels; not live build/CI status |
| password-workflow.gif | Looping conceptual animation of account registration and login |
| password-workflow-still.png | Static alternative to the animated diagram |

The animation illustrates the implemented workflow. It is not a recording of authentication timing and contains no account passwords, salts, or hashes. Actual application captures live in `../screenshots/`.

No third-party animation service, custom README JavaScript, CSS animation, external font, or repository-specific username is required. The GIF loops automatically where animated images are enabled. GitHub supports the Mermaid class diagram in the parent README; other Markdown viewers may display its source instead.
